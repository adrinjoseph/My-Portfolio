06 — Featured Project

A 200-day systems engineering build, end to end

In ProgressAI/ML Systems Engineering

Core AI Gateway

A 200-day monorepo covering the full AI/ML systems stack — from math and classical ML built from scratch, up through deep learning, MLOps, GenAI agents, a full-stack gateway, and edge/Rust inference.

GitHub Codecode

The Problem

Most ML learning paths stay in notebooks — models trained once, never served, monitored, or scaled. That leaves a real gap between "I can train a model" and "I can engineer a production AI system."

The Approach

A single monorepo, built in phases over 200 days — implementing math and classical ML from scratch first, then layering on deep learning, MLOps, GenAI/agents, a full-stack streaming gateway, and finally Rust/CUDA/WASM edge compute.

Structure

modules/math_core → services/ml_inference → platforms/mlops_pipeline → engines/edge_accelerator

Roadmap

Phase 1: math & data foundations from scratch → Phase 2: classical ML + XAI → Phase 3: deep learning + CV → Phase 4: MLOps, orchestration & graph DBs → Phase 5: GenAI, LLMs, agents & RAG → Phase 6: full-stack streaming (Next.js/Express, SSE) → Phase 7: Rust, CUDA & WASM edge compute.

Why It Matters

Every layer of the stack — from a hand-rolled autograd engine to a deployed inference gateway — is built and understood first-hand, instead of assumed from a library.
